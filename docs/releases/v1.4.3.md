# VoicePrompt 1.4.3 - Quiet background AI cleanup

- Optional AI cleanup failures no longer show a notification. Original text and earlier
  validated corrections are retained; History keeps the original and fallback count.
  Each fallback reason is written to the diagnostic log without transcript content.
- Background cleanup gets more time: 20 seconds on the backend and 25 seconds in Windows,
  instead of eight seconds on both sides. The extra client time covers transport overhead.
- Stop still schedules no new AI request and never waits for AI. Once the remaining
  transcription is ready, one paste combines available corrections with original text
  elsewhere. Late AI results cannot change the clipboard or saved transcript.
- Transcription, storage and clipboard/paste problems still produce actionable notifications.
  Concurrency limits, no-retry behavior and edit validation remain unchanged.

## Downloads

- **VoicePrompt-Setup.exe:** Windows x64 1.4.3, per-user upgrade preserving settings,
  History and existing OAuth configuration. Requires .NET 8 Desktop Runtime.
  The installer is unsigned and does not bundle OAuth credentials.
- **VoicePrompt-Android.apk:** unchanged signed Android 1.2.0 APK from release 1.4.2.
- **SHA256SUMS.txt:** SHA-256 checksums for both downloads.

Self-hosted backends must be updated to receive the longer server-side timeout.
This release does not guarantee that every passage will be cleaned or fix every
provider rejection. Short recordings and unfinished AI work retain the original transcription.

## Validation

379 Windows core tests and 439 backend tests passed, along with the native Windows
controller probe, backend lint and type checks. Regression coverage includes quiet network,
HTTP 502, invalid-edit and timeout fallback; longer-running background responses; and
immediate final assembly with no late paste.

The hosted API has been updated. Authenticated synthetic Czech and English checks
successfully removed duplicate phrases while preserving port 8443. These small checks
are not a guarantee of recognition accuracy or production latency.
