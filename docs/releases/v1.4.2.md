# VoicePrompt 1.4.2 - Background AI cleanup and a simpler dictation popup

## New since 1.3.1

- **A simpler Windows popup:** only the recording/finishing state and a three-line preview
  of recent text. Saved/transcribed/pending counters and AI diagnostic details are removed.
  The popup stays click-through and does not steal focus. Errors still appear through
  notifications, History and operational logs.
- **Optional GPT-5.6 Luna cleanup**, off by default in Settings. It primarily removes clear
  accidental repetitions and corrects unambiguous recognition mistakes, without rewriting
  your style. Overlapping text windows span multiple audio chunks, so the model can inspect
  their seams rather than processing each audio chunk in isolation.
- **No final AI wait:** Stop schedules no new model request. One final paste combines
  already available corrections with the original unprocessed ending. Late AI responses
  never replace text that has already been pasted.
- **Bounded background work:** one active cleanup request, no queue of stale snapshots,
  time-based dispatch for shorter passages, and an editable overlap between text windows.
  New speech is merged using exact original-text edit positions.
- **Safer, useful edit validation:** duplicate-word and filler deletion can change ordinary
  spaces, while exact anchors, paragraph boundaries and protected numeric/technical
  literals are checked. Failures retain original text or previously accepted corrections.
- **Copy original in History:** both the assembled result and original MAI transcript
  remain available. An unprocessed ending is normal and does not trigger an AI failure
  warning. Logs now distinguish real request/validation failures.

## Recording controls included from the 1.3 series

Hands-free start/stop was introduced in **1.3.1** and remains available alongside
push-to-talk:

- **Hold Ctrl+Alt+Space:** speak, then release to finish and paste.
- **Press Ctrl+Alt+Shift+Space:** start hands-free recording; press again to finish.
  You can switch windows while speaking. Focus the intended destination **before stopping**.
- **Esc:** discard the current dictation.

Both shortcuts are configurable. Long sessions have no five-minute recording stop.
Encrypted checkpoints and the Recovery tab protect interrupted recordings; Recovery never
pastes automatically. These long-session and recovery features are carried forward from
1.3.1, not newly introduced in 1.4.2.

## Downloads

- **VoicePrompt-Setup.exe:** Windows x64 **1.4.2**. Requires .NET 8 Desktop Runtime.
  The per-user installer preserves existing settings and OAuth configuration, is not
  code-signed, and does not bundle OAuth credentials.
- **VoicePrompt-Android.apk:** unchanged, signed **Android 1.2.0** APK, identical to the
  APK in 1.3.1. Included for convenient direct download; no Android code changes.
- **SHA256SUMS.txt:** SHA-256 checksums for both downloads.

Existing users must opt in to AI cleanup unless it was already enabled. New Windows
installations need the Desktop OAuth setup described in the README. Self-hosted backends
must also be updated for the refinement endpoint and its exact-edit response; the hosted
backend has already been updated and still enforces its account allowlist.

## Privacy and limitations

Cleanup sends text and preceding context through the authenticated backend to the cloud
model. History stores both versions in the existing **unencrypted, 48-hour local text
cache**; audio recovery checkpoints use Windows current-user DPAPI encryption.

Cleanup is best effort: short dictations or the final words may remain entirely original.
Some Czech repetitions across a read-only context boundary are still missed. AI cannot
recover words omitted by speech recognition and can make incorrect edits; use Copy
original when needed. Remaining MAI transcription, persistence and clipboard operations
still take time even though there is no final AI wait.

Hands-free paste targets the window selected at Stop. Choosing the wrong editable window
can paste there; changing focus while finishing skips automatic paste. The app sends one
Ctrl+V, never Enter.

## Validation

**378 Windows core tests and 438 backend tests passed**, plus the complete native Windows
controller probe, including the compact two-part popup layout. Three opt-in backend
integration cases were skipped in the normal suite. Ruff and mypy passed.

Separate real-cloud synthetic Czech and English checks removed repeated phrases while
preserving protected literals. A rolling background probe completed final assembly in
2 ms without waiting for AI. These are synthetic checks, not a guarantee of microphone
accuracy or end-to-end network latency.
